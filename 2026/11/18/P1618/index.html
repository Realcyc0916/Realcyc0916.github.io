[
x:y:z=A:B:C
]

最直接的方法是使用三重循环，分别枚举三个三位数：

由于每个数都有 900 种可能，时间复杂度为：

[
O(900^3)=O(1000^3)
]

显然，这样的枚举存在大量冗余。

注意到题目给出了三个数之间的比例关系，这意味着它们并不是独立的。若已知第一个数，是否就能够确定另外两个数？

二、两个整数之比的性质

首先考虑两个正整数之比。

定理 1：

设 (a,b,c,d) 为正整数，且：

[
a:b=c:d
]

如果 (c:d) 是最简整数比，即：

[
\gcd(c,d)=1
]

那么：

[
\boxed{c\mid a,\quad d\mid b}
]

换句话说，必然存在正整数 (k)，使得：

[
a=kc,\qquad b=kd
]

证明

由：

[
\frac ab=\frac cd
]

交叉相乘可得：

[
ad=bc
]

因为 (\gcd(c,d)=1)，根据贝祖等式（Bézout’s Identity），存在整数 (u,v)，使得：

[
cu+dv=1
]

两边同时乘以 (a)：

[
acu+adv=a
]

代入 (ad=bc)：

[
acu+bcv=a
]

整理：

[
c(au+bv)=a
]

因为 (a,b,u,v) 均为整数，所以 (au+bv) 也是整数。

因此：

[
\boxed{c\mid a}
]

于是存在正整数 (k)，使得：

[
a=kc
]

再代入 (ad=bc)：

[
kcd=bc
]

因为 (c>0)，可得：

[
b=kd
]

所以：

[
\boxed{(a,b)=(kc,kd)}
]

证毕。

这说明：对于一个最简整数比，其他满足相同比例的正整数对，只可能是它的整数倍。

三、推广到 (n) 个整数

现在考虑任意 (n) 个正整数：

[
a_1:a_2:\cdots:a_n=c_1:c_2:\cdots:c_n
]

需要注意，最简整数比并不要求各个数两两互质。

例如：

[
6:10:15
]

虽然其中任意两个数的最大公约数都大于 1，但：

[
\gcd(6,10,15)=1
]

因此它仍然是最简整数比。

定理 2：

若：

[
\gcd(c_1,c_2,\ldots,c_n)=1
]

且两组正整数满足上述比例关系，则必然存在正整数 (k)，使：

[
\boxed{a_i=kc_i,\quad \forall i\in{1,\ldots,n}}
]

证明

由比例关系，存在一个正有理数 (r)，使得：

[
a_i=rc_i,\qquad i=1,2,\ldots,n
]

根据推广的贝祖等式，当：

[
\gcd(c_1,c_2,\ldots,c_n)=1
]

时，存在整数 (x_1,x_2,\ldots,x_n)，满足：

[
c_1x_1+c_2x_2+\cdots+c_nx_n=1
]

这里的推广可以通过反复应用两数的贝祖等式得到。

两边同时乘以 (r)：

[
rc_1x_1+rc_2x_2+\cdots+rc_nx_n=r
]

由于 (a_i=rc_i)，代入得：

[
a_1x_1+a_2x_2+\cdots+a_nx_n=r
]

因为所有 (a_i,x_i) 都是整数，所以：

[
\boxed{r\in\mathbb Z}
]

而 (r>0)，因此令 (k=r)，便得到：

[
\boxed{a_i=kc_i}
]

证毕。

也就是说，只要右侧是最简整数比，左侧所有对应的数就一定是右侧各数的同一个正整数倍。

四、回到原题

我们需要满足：

[
x:y:z=A:B:C
]

题目并没有保证 (A,B,C) 两两互质，也没有保证它们整体互质。

但这并不影响上述定理的应用。

设：

[
g=\gcd(A,B,C)
]

当 (A>0) 时，可将比例化为：

[
a:b:c=\frac Ag:\frac Bg:\frac Cg
]

由最大公约数的性质：

[
\gcd(a,b,c)=1
]

因此根据定理 2，任何合法解必然满足：

[
(x,y,z)=(ka,kb,kc)
]

其中 (k) 是正整数。

这说明 (x,y,z) 之间存在确定的关系。特别地，由：

[
x=ka,\qquad y=kb,\qquad z=kc
]

可以得到：

[
\boxed{y=\frac{B}{A}x,\qquad z=\frac{C}{A}x}
]

所以，当第一个数 (x) 确定后，另外两个数便唯一确定。

因此，我们根本不需要同时枚举三个数，只需要枚举第一个数。

实际上，得到这两个公式只需要比例的定义；前面的数论证明进一步说明了合法整数解的结构。

五、优化后的枚举

直接枚举：

[
100\le x\le999
]

对于每一个 (x)，分别计算：

[
y=\frac{xB}{A},\qquad z=\frac{xC}{A}
]

接着反过来检查三个数是否满足题目要求。

首先检查 (y,z) 是否为整数。

由于 C++ 的整数除法会截断小数部分，不能直接认为：

得到的数就一定满足比例关系。

例如：

[
x=101,\quad A=2,\quad B=3
]

此时：

[
\frac{101\times3}{2}=151.5
]

但整数除法会得到 (151)，并不符合原本的比例。

因此，生成 (y,z) 后，需要反过来验证：

[
\boxed{Ay=Bx,\qquad Az=Cx}
]

这两个等式成立，当且仅当生成的整数满足指定的比例关系。

然后继续检查：

  1. (y,z) 是否都是三位数。
  2. 三个数的九个数位是否均在 (1\sim9) 之间。
  3. 九个数位是否没有重复。

如果全部满足，就输出这组解。

由于 (x) 本身按升序枚举，结果也自然满足题目要求的输出顺序。

对于 (A=0)，由于 (B,C>A)，而题目要求 (x) 是正的三位数，不可能满足比例关系，因此直接输出 No!!!。

七、复杂度分析

原本的三重枚举需要：

[
O(1000^3)
]

通过比例关系，只需要枚举第一个数 (x)，总共最多 900 次。

每次计算另外两个数并判断比例的操作都是 (O(1))，检查九个数位也是 (O(1))。

因此时间复杂度降为：

[
\boxed{O(1000)}
]

空间复杂度为：

[
\boxed{O(1)}
]
